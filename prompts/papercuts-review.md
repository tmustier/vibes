This is an explicit one-off papercut review. Do not create a recurring job, hook, or automatic session miner.

1. Run `papercut review --all --limit 100` from the current working directory.
2. Combine those recorded entries with only small, real friction directly evidenced in the visible current session. Exclude blockers, tracked issues, requested work, accomplishments, and speculation. Never expose secrets, credentials, tokens, customer/private content, or raw messages.
3. Summarize recurring themes, frequency/evidence, global versus repo-local scope, likely causes, and meaningful singletons.
4. Recommend the smallest durable improvements and where each belongs. Do not edit files, create Linear/GitHub issues, or append new papercuts unless the user asks.
